# Guion de video (4 minutos 45 segundos)

Grabar la aplicación real y explicar con palabras propias. Este guion no constituye un video realizado.

| Tiempo | Demostración |
|---|---|
| 0:00–0:30 | Compilar con Maven, mostrar 14/14, abrir el JAR y explicar Swing/FlatLaf. |
| 0:30–1:15 | Registrar/modificar una vacuna, mostrar una validación, explicar clave y tarifa polimórfica. |
| 1:15–1:45 | Mostrar propietarios, correo único y descuentos 0 %, 12 % y 30 %. |
| 1:45–2:45 | Abrir atención, agregar/quitar líneas, comprobar importes, iniciar y concluir. Rechazar una transición inválida; explicar Atencion.this. |
| 2:45–3:30 | Mostrar reportes, exportar/restaurar catálogo y reiniciar para demostrar persistencia. |
| 3:30–4:15 | Mostrar bitácora y explicar revisar, reloj inyectado, interrupt/join y EDT/SwingWorker. Las fechas simuladas se prueban sin cambiar el reloj del equipo. |
| 4:15–4:45 | Mostrar diagrama y bitácora de IA; explicar una regla funcional, un tipo interno y una transacción. |

Preparar también la defensa de 10 minutos: modificar una fórmula, agregar una validación y explicar inicialización, composición/agregación y reconstrucción polimórfica JDBC.
